CRED Placement Guide

Eligibility Criteria


No strict published CGPA cutoff; freshers are welcome but internship/project experience is strongly preferred
Open to all engineering branches with strong OOP programming skills (Java/Python)
Good personal financial credit history is informally noted as a values-fit signal


Selection Process


Take-home Coding Assignment (~24-hour deadline, evaluated for code quality/architecture)
DSA & Puzzles Round
Machine Coding / Low-Level Design Round (LRU cache, key-value store, design patterns)
System Design + Managerial Round (often with senior engineering leadership)


Key Preparation Areas


Clean, modular, production-quality code (SOLID principles, design patterns)
LLD problems: caching systems, idempotency, schema design
Fintech-relevant system design (data de-duplication, failure handling)
Strong DSA fundamentals (medium LeetCode level)


Timeline


Primarily off-campus/direct hiring; hires freshers on a rolling basis rather than fixed campus cycles
