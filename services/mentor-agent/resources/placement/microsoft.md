Microsoft Placement Guide

Eligibility Criteria


Minimum 7.0+ CGPA / 70% (consistently applied across 10th, 12th, and graduation) for the standard SDE track
Open to CS, IT, ECE and related branches; B.Tech/B.E. final year or M.Tech/MBA per role
No active backlogs at time of application
Hiring happens both through invited campus drives (Tier 1/2 colleges via Microsoft's University Program) and off-campus/Engage program applications


Selection Process


Online Assessment — 60–90 min, 3–4 coding problems, sometimes optional MCQs
Technical Interview Round 1 — DSA and coding
Technical Interview Round 2 — DSA + system design/project deep-dive
Hiring Manager / "As Appropriate" (bar-raiser) round
HR / culture-fit round


Key Preparation Areas


DSA across arrays, trees, graphs, dynamic programming — 100+ practiced problems
System design basics (URL shortener, chat app style questions) for SDE roles
Strong grasp of OOP concepts and design patterns
Ability to walk through personal/academic projects in depth


Timeline


Campus drives typically run in the standard India placement season (Aug–Dec for pre-placement/Day 1-2 slots)
Microsoft Engage (pre-internship program) usually opens applications a few months before summer internship season
Not all colleges get a direct visit — many students access Microsoft via off-campus/Engage rather than a TPO-scheduled drive
