Flipkart Placement Guide

Eligibility Criteria


60% / 6.5 CGPA minimum across 10th, 12th, and graduation
Open primarily to B.E/B.Tech/M.E/M.Tech (CSE, IT, ECE), but strong programmers from other branches can apply
No active backlogs at the time of the drive


Selection Process


Online Assessment (~90 min, 2-3 DSA problems, medium-hard on HackerRank)
Technical Interview Round 1 (DSA + CS fundamentals)
Technical Interview Round 2 / Machine Coding (build a working module, e.g., LLD problem)
HR / Hiring Manager Round


Key Preparation Areas


Strong DSA (arrays, trees, graphs, DP) in Java/C++/Python
Machine coding / low-level design (OOP, design patterns)
Basic system design concepts
Also hires via Flipkart GRiD (annual nationwide coding competition) as an alternate entry route


Timeline


Campus drives run through the placement season (Aug–Feb); also runs GRiD (hackathon-style hiring) separately, open to 2026–2029 batches
