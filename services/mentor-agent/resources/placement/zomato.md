Zomato Placement Guide

Eligibility Criteria


65% / 6.5 CGPA minimum across 10th, 12th, and graduation
Open to all engineering branches; CS/IT preferred for SDE roles
No active backlogs


Selection Process


Online Coding Assessment (90–120 min, 2-3 DSA + debugging questions)
Technical Interview(s) (2-3 rounds — DSA, projects, system design)
Managerial / Team-Fit Round (values-based: customer focus, innovation, ownership)
HR Round


Key Preparation Areas


DSA and debugging (Java/C++/Python/Go)
System design fundamentals
STAR-format stories reflecting Zomato's core values
For analyst/BA roles: SQL and case-study/product-metrics practice


Timeline


Runs both on-campus and off-campus drives through the year, with a concentration in the August–February placement window
