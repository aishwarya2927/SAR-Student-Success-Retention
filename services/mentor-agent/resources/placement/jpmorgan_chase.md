JPMorgan Chase Placement Guide

Eligibility Criteria


Bachelor's degree for Analyst/junior tech roles (Master's/MBA/PhD preferred for senior/quant/strat roles)
Strong academic record expected (roughly 7.5+ CGPA/first class or equivalent, higher at top-tier campuses)
Programming proficiency (Python, Java, C++, SQL) expected for technology roles; strong quant/stats background for quant roles
Students graduating in the current or following year (per program-specific windows); availability for the full internship/program duration required


Selection Process


Online application via careers portal/campus system (Workday-based)
Online assessment - includes game-based (Pymetrics) cognitive/behavioral tests and technical/coding tests for engineering roles
First-round interview (telephonic/virtual/on-campus) - technical for tech roles, or resume/behavioral for business roles
Group activity/case exercise (when multiple candidates are shortlisted)
Final round/"Superday" - back-to-back technical + HR/behavioral interviews, sometimes including a case or presentation task


Key Preparation Areas


Data structures, algorithms, OOPs, DBMS for Software Engineer track
Financial markets/valuation/accounting basics for Investment Banking, Markets and Asset Management tracks
Pymetrics-style cognitive games - practice pattern recognition and risk-based decision games
Resume-driven behavioral questions (STAR method) and situational judgment


Timeline


Summer Analyst/Internship applications generally open in the second half of the calendar year (August-October) for the following summer
Campus drives at top Indian institutes run alongside global cycles; hackathons like "Code for Good" are used as an additional sourcing channel
Internships run 8-12 weeks (typically May-July); strong performers receive Pre-Placement Offers (PPOs) for full-time roles
