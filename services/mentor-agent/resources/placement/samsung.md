Samsung Placement Guide

Eligibility Criteria


70% or above in 10th, 12th, and graduation (CGPA ~7.0–7.5+ depending on drive/role)
Open to B.Tech/B.E./M.Tech/M.E. in CS, IT, ECE, EE
No active backlogs


Selection Process


GSAT / Online Test (aptitude — Verbal, Logical Reasoning, Quantitative — plus coding round for R&D roles)
Technical/Coding Interview(s) (DSA, data structures — e.g., segment trees, graph problems — and CS fundamentals)
Executive Interview (HR-style, communication and negotiation assessment)
Work Capability Interview (conceptual/technical depth check)
Medical Test (final stage before offer)


Key Preparation Areas


Strong DSA fundamentals — Samsung R&D (SRIB) coding rounds are known to be rigorous (implement-from-scratch, no STL/library shortcuts in some rounds)
C, C++, and Java proficiency
For hardware-track roles: basic electronics/VLSI concepts
Communication skills — assessed distinctly in the Executive Interview stage


Timeline


Samsung R&D Institute Bangalore (SRIB) and other centers run structured on-campus and virtual drives (software and hardware tracks) through the Aug–Feb placement season
