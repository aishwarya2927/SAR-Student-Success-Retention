Zepto Placement Guide

Eligibility Criteria


No universally published CGPA cutoff; CGPA above 7.0 is a safe general benchmark for shortlisting
Open to Bachelor's/Master's graduates across CS, Engineering, and quantitative fields (role-dependent)
Strong preference for candidates with solid projects/internships and GitHub activity, especially if CGPA is on the lower side


Selection Process


Resume/Profile Screening
Online Coding Assessment (DSA-focused)
Technical Interview(s) (DSA + basic System Design/HLD-LLD, increasingly common even for freshers)
Hiring Manager / HR Round


Key Preparation Areas


DSA fundamentals and practical coding ability
Basic system design (HLD/LLD) — a growing expectation even at fresher level at high-growth startups
Strong, deployed personal projects with GitHub links
Domain-specific prep for roles like Data Scientist (ML fundamentals, feature engineering)


Timeline


Hires mainly through off-campus drives and rolling hiring; less dependent on a fixed campus calendar than larger firms
