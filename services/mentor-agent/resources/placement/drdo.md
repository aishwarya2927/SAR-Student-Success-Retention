DRDO Placement Guide

Eligibility Criteria


B.Tech/B.E. (or equivalent) in Mechanical, Electronics, Electrical, Computer Science, Chemical Engineering, or related disciplines
Minimum ~60% aggregate in the qualifying degree (CGPA-to-percentage conversion per AICTE norms if no official formula exists)
A valid GATE score is mandatory for most DRDO Scientist 'B' recruitment cycles; age limit typically 21–28 years


Selection Process


GATE Score Shortlisting (primary entry route) — or DRDO SET (Scientist Entry Test) when conducted for large vacancy counts
Written/Descriptive Test (for candidates without sufficient vacancies covered by GATE alone — technical + aptitude sections, negative marking)
Personal Interview (technical + suitability assessment by the Recruitment & Assessment Centre, RAC)
Document Verification & Medical Examination


Key Preparation Areas


GATE-level command of core engineering subjects in your discipline
DRDO SET pattern: Section A (core subject knowledge) + Section B (general aptitude/awareness)
Awareness of DRDO's key focus areas (missiles, radars, combat systems, materials, avionics)
Previous GATE and DRDO SET question papers for practice


Timeline


GATE-based Scientist 'B' recruitment cycle typically opens after GATE results (usually mid-year); select institutes also have direct campus placement tie-ups with specific DRDO labs
